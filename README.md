# 하루메모 — 아이폰 설치 안내

메모와 일정을 한곳에서 관리하는 아이폰용 앱입니다. 오프라인에서도 동작합니다.

## 설치 (1분)
1. 아이폰 **Safari**로 https://redjin83.github.io/haru-memo-app/ 에 접속합니다.
2. 하단 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**
3. 홈 화면의 **하루메모** 아이콘으로 실행!

## 업데이트
새 버전이 배포되면 앱을 켤 때 "새 버전이 있어요" 안내가 뜹니다. **업데이트**를 누르면 바로 적용되고, 저장한 메모·일정은 그대로 유지됩니다.

## 데이터
모든 메모와 일정은 아이폰 안에만 저장되며 어디에도 전송되지 않습니다.
기기를 바꾸기 전에는 **설정 → 백업 파일 내보내기**로 백업해 두세요.

---
이 저장소는 배포용입니다. 파일은 소스 저장소의 `scripts/deploy.sh`로 자동 복사되니 직접 수정하지 마세요.
