# 다이아몬드 레거시 — 다운로드

완전 오프라인 모바일 야구 매니지먼트 게임 (Android)

## 설치 방법
1. 오른쪽 **Releases**에서 최신 버전의 `diamond-legacy-x.y.z.apk`를 휴대폰으로 내려받습니다.
2. 파일을 열고, 처음이라면 **"이 출처 허용"**(출처를 알 수 없는 앱 설치)을 켭니다.
3. 설치 후 실행!

## 업데이트
새 버전이 나오면 앱을 켤 때 자동으로 알려 드립니다. **업데이트**를 누르면 앱 안에서 내려받아 설치되며, 저장 데이터는 그대로 유지됩니다.

## 파일 안내
- `manifest.json` — 앱이 최신 버전을 확인하는 파일 (자동 갱신, 직접 수정하지 마세요)

인터넷 연결은 업데이트 확인에만 사용합니다. 게임은 오프라인에서 모두 플레이할 수 있습니다.
